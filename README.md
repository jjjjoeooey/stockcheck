# stockcheck —— 七维股票体检 / 初筛模型

把「换手、量能、KDJ 金叉、相对位置、新布林极限、相对压力位、基本面」七个维度各自打 0~100 分，
再按权重合成总分，输出**单票诊断报告**或**批量排行榜**。

> 这是**量化打分/筛查工具**，不是投资建议。分数只反映当前数据的形态，不预测涨跌。
>
> **数据从哪来**：平台内置「联网同步」，直接从东方财富拉**前复权**日线和 PE/PB，所以 K 线和你软件里看到的一致（前复权口径）。「生成演示」按钮造的是**模拟数据**，只用于看界面形态，和真实行情无关。

## 0. 网页平台（推荐）

除了命令行，现在带一个本地 Web 平台：上传、打分、看图、调权重、批量筛选都在浏览器里完成。

```bash
./run.sh web            # 或 python -m stockcheck.server --port 8766
```

浏览器打开 **http://127.0.0.1:8766** （macOS 也可以直接双击 `双击启动平台.command`）。

平台功能：

- **排行榜**：七维得分一目了然，支持搜索、最低分过滤、点表头排序；
- **单票分析**：顶部搜索框输入代码/名称回车，或点排行榜任意一行；右侧抽屉展示七维得分卡、布林带 K 线图、KDJ 曲线、换手率图、结论；支持**日K / 周K / 月K**切换，图上直接标出 KDJ 与布林数值；
- **板块扫描**：选行业/概念/地域板块 → 按价格、市值、成交额、ST、亏损筛选（换手/涨幅/PE 已计入打分，不做过滤，避免重复计算） → 一键深度扫描前 N 只 → 按六维总分排序，最高分标「最高分」；
- **全市场**：一次拉全 A 股（约 5500 只）快照做粗筛，选中前 N 只批量深度扫描，不用一只只导；
- **相似形态库**：拿当前 60 日走势，在已入库股票的历史里找最像的片段，统计之后 5/10/20 天的表现；
- **联网同步**：输入代码即可拉取真实前复权日线（默认 600 根）+ PE/PB，**不需要任何导出**；
- **数据上传**：拖拽 CSV/Excel，支持多选批量导入；基本面表单独上传并自动匹配重算；
- **直接粘贴**：把 K 线数据 `Ctrl+C` 复制后粘进文本框即可解析入库，导出功能找不到时用；
- **权重设置**：七个滑块实时调权，套用「技术优先 / 基本面优先 / 趋势优先」预设，点一下全体重算；
- **导出**：一键导出带 BOM 的 CSV，Excel 直接打开不乱码；
- **持久化**：数据存在 `data/platform.db`（SQLite），关掉服务不丢，改权重可原地重算。

## 2. 指南针的数据怎么进来

**先说结论**：指南针没有公开 API，本地数据是加密的 QMI 格式，程序**不能直接读**。
如果只是想让 K 线和软件一致，别导出，直接用平台里的「联网同步」；只有当你必须用指南针自己的数据（比如自定义复权、特殊品种）时，才需要下面的导出/粘贴。

### 方式 A：直接联网同步（推荐，30 秒）

平台「数据上传」页 → ③ 联网同步 → 输入 `600519, 300750, 000001` → 同步行情。

- 数据源：东方财富，**前复权**日线，默认 600 根；
- 同时取 PE(动)、PB、总市值；
- 和指南针/同花顺的**前复权** K 线应一致；如果你软件里是「不复权/后复权」，除权日附近会有差异。

命令行也一样（不需要装 akshare）：

```bash
./run.sh one --code 600519
./run.sh one --code 300750 --fundamentals data/基本面.csv
```

### 方式 B：从指南针导出（单只）

不同版本菜单名略有差异，按顺序找这三个地方：

1. **K 线界面右键** → 菜单里找「数据导出 / 导出数据 / 导出 K 线」；
2. **顶部菜单「系统 / 工具 / 数据」** → 「数据管理 / 数据导出」；
3. **报价列表右键** → 「导出数据」，通常可选 Excel 或文本。

导出时选 **CSV / TXT / Excel**，保留表头，最好选**前复权**。需要的列：

| 必需 | 列名可写成 |
|---|---|
| 日期 | `日期` / `交易日期` / `date` |
| 开盘 | `开盘` / `开盘价` |
| 最高 | `最高` / `最高价` |
| 最低 | `最低` / `最低价` |
| 收盘 | `收盘` / `收盘价` |
| 成交量 | `成交量` / `vol` |
| 换手率（建议） | `换手率` / `换手` |

然后拖进平台，或：

```bash
./run.sh one --file ~/Downloads/600519.csv --code 600519
```

### 方式 C：复制粘贴（导出找不到时的兜底）

K 线界面 `Ctrl+A` 全选 → `Ctrl+C` → 平台「数据上传」页 → ④ 直接粘贴 → 填代码 → 解析并入库。

注意第一行要有列名，否则程序不知道该列是什么。

### 方式 D：报价列表批量导出

1. 报价列表把「代码、名称、换手率」等列显示出来，全选复制到 Excel；
2. 存成 `pool.csv`，`文件` 列指向每只股票的日线文件：

```csv
文件,代码,名称
data/600519.csv,600519,贵州茅台
data/300750.csv,300750,宁德时代
```

```bash
./run.sh screen --universe data/pool.csv --top 20 --min-score 70
```

> 代码列务必按**文本**保存，否则 `000001` 会变成 `1`。本程序读表时默认按文本读，已规避。
> 别去拷指南针目录里的 `.qmi` 文件——那是加密格式，读不了。

### 和指南针对不上时，先看这三件事

1. **周期**：指南针默认常常是周K，本平台默认日K。同一个 KDJ 参数，周线和日线数值完全不同（例：茅台周K K=81.2，日K K=85.4）。
2. **复权**：两边都切「前复权」再比；不复权会在除权日出现假跳空。
3. **私有指标**：指南针的「优化布林线」「新布林极限」是它自己的算法，名字和通用指标一样但公式不同，**数值不能直接比**。
   本平台用的是标准 BOLL(20,2) 和自研的「新布林极限 = 上轨突破度 + 带宽扩张」，逻辑写在 3.4 节。

实测（贵州茅台，2026-11-09）：

| 指标 | 本平台 | 指南针 | 结论 |
|---|---|---|---|
| 日线 KDJ | K 82.140 / D 85.593 / J 75.234 | K 82.140 / D 85.593 / J 75.234 | **完全一致** |
| 周线 KDJ | K 81.156 / D 70.026 / J 103.415 | K 81.156 / D 70.030 / J 103.409 | 差 0.006，初始值/四舍五入 |
| MA20（日/周） | 1365.91 / 1304.70 | 1365.91 / 1304.70 | **完全一致** |
| 优化布林轨道 | 标准 ±2σ：[1242.53, 1489.30] | [1288.70, 1443.12] / [1234.66, 1497.17] | 中轨一致，轨道宽度是私有自适应参数 |
| 新布林极限 | 自研口径 | 2.556（上轨 2.950） | **同名不同算法**，不可直接比 |

> **复刻进展（2026-11-09）**：用连续 7~8 个交易日的截图值做联合拟合，确认结构是
> `I = BIAS18 − MA30(BIAS18)`，轨道 `±AVEDEV(I,30)`。
> - 上证指数：7 个点误差 **0.02**，几乎逐位一致；
> - 创业板指：形状一致，幅度约大 **10%**（可能还有按波动率缩放的一层）；
> - 个股：方向一致但幅度有偏差（如 600519 复刻 2.14 vs 指南针 2.56）。
>
> 平台已在「新布林极限」说明里显示「指南针口径 …（近似）」，**仅供对照，不参与打分**。要逐位一致仍需官方公式或更多序列。

## 2.95 因子有效性检验（2026-11）

用 267 只股票、29 个横截面（2023-2026）做了 IC 检验：

- 6 个技术因子对 5/20 日收益的 IC 都在 ±0.04 以内，t 值基本不显著；
- 唯一稳定显著的是**负向**：换手率 250 日分位（20 日 IC -0.059，t=-2.38；60 日 -0.050，t=-2.79）、20 日动量（60 日 IC -0.049）——高换手、短期大涨的票，之后偏弱（反转）；
- 因此权重从「技术 82 / 基本面 18」调整为「技术 70 / 基本面 30」，并下调换手、压力位权重。

## 3. 七维口径与打分逻辑

先说明一点：下面每个「分」都是 0~100，**50 分≈中性**。曲线都是分段线性/高斯形状，可读性优先于精妙。

### 3.1 换手（权重 9）

- 主口径：最新交易日换手率(%)；无该列时用**量比**（当日量 / 前 20 日均量）替代。
- 三个子项：
  - `level`（50%）：换手 3%~8% 最健康，<0.8% 太冷、>15% 过热（过热时总分强制 ≤55）；
  - `pct_250`（30%）：当日换手在近 250 日分布中的分位，25→100 分线性映射；
  - `vs_5d`（20%）：当日 / 近 5 日均换手，≈1 为平量，1.5~2.5 为温和放量，>4 视为异常。

### 3.2 量能（权重 9）

成交量单独成一维，识别「放量 / 缩量 / 地量 / 天量 / 量价背离」：

```
v_ratio  = 当日量 / 前20日均量
v_ratio5 = 近5日均量 / 前20日均量        # 量能趋势
v_pct250 = 当日量在近250日中的分位
price_5d = 近5日涨跌幅
```

| 状态 | 判定 | 基础分 |
|---|---|---|
| 放量上涨 | 5日涨幅 >2% 且 5日量比 >1.3 | 82 |
| 缩量回调 | 5日下跌 且 5日量比 <0.85 | 68 |
| 放量下跌 | 5日跌幅 >2% 且 5日量比 >1.3 | 22 |
| 地量 | 量能分位 <10% | 45 |
| 天量 | 量能分位 >95% | 35 |
| 平量 | 其余 | 52 |

再叠加：量能趋势 >1.2 加 6 分、<0.85 减 4 分；当日温和放量上涨加 5 分；放量滞涨（>3 倍且不涨）减 12 分；量价背离减 8 分。

### 3.3 KDJ 金叉（权重 16）

- 标准 KDJ(9,3,3)，K/D 用 1/3 平滑（与通达信一致）。
- 金叉 = 当日 `K > D` 且前一日 `K <= D`。
- 打分看三点：
  - **金叉位置**：金叉当日 K 越低越好（K<20 低位金叉加分）；
  - **新鲜度**：当日金叉最高，20 日前金叉衰减到中位；
  - **力度**：金叉日 K 的抬升幅度 + 金叉前 J 是否曾 <0（超卖修复）。
- K 在 D 下方的空头排列得 26~32 分；高位钝化（K>70 且 K>D）给 56~62 分。

### 3.4 相对位置（权重 12）

```
position = (收盘 - 近250日最低) / (近250日最高 - 近250日最低)
```

- 甜点在 **0.72** 附近（有趋势但不过热），高斯曲线，宽度 0.26；
- `>0.95` 额外扣分（追高风险），`<0.1` 基本在 10~20 分。

### 3.5 新布林极限（权重 14）

把「突破力度」和「开口」分开，**两者共振才算真突破**：

```
breakout        = (收盘 - 上轨) / (上轨 - 中轨)     # 上轨外为正
width_expansion = 当前带宽 / 近60日平均带宽         # >1 表示开口放大
% B             = (收盘 - 下轨) / (上轨 - 下轨)
```

- 基础分 = 55% 突破度 + 45% 开口度；
- **缩口假突破**（突破但带宽没放大）总分压到 62 以下；
- **跌破中轨**（`%B < 0.5`）属于空头背景，此时带宽放大是下跌加速，总分压到 45 以下。

### 3.6 相对压力位（权重 10）

- 用**近 250 日成交量分布（筹码分布）**找现价上方的成交密集区作为 `R1`；
  找不到则用近一年最高价。
- `R2` = 近一年最高价（若与 R1 不同），代表突破后的第二目标。
- 距离越远分越高；但**下跌趋势里「上方空间大」是深套区，不是利好**：
  距年内高点回撤 >15% 时按回撤幅度打折，且在 20 日均线下再乘 0.85。

### 3.7 基本面概况（权重 30）

按可用字段加权，缺哪个就剔除哪个并重新归一（不会因为缺数据把股票判死）：

| 字段 | 权重 | 打分要点 |
|---|---|---|
| ROE | 30% | 15% 以上优秀，10% 及格，<5% 低分 |
| 净利润增速 | 25% | 25%+ 优秀，负增长低分 |

## 6. 已知限制

- **只做形态打分，不做预测**。技术指标天然滞后，金叉/突破的假信号比例不低，务必配合量能和基本面确认。
- 相对压力位用的是**成交量分布近似**，不是严格筹码分布（拿不到逐笔/持仓数据）；次新股、长期停牌股的分布会失真。
- 生命周期不到 250 日的次新股，相对位置和压力位参考性下降（报告会提示）。
- 缺少基本面数据时，总分按技术面重新归一；**跨股票比较时请确保口径一致**（要么都有基本面，要么都没有）。
- 联网行情来自东方财富公开接口，可能限频/变更（程序已做单页重试与容错）；商业用途请自建行情源。
- 「全市场」里的**快照分**只用换手/量比/涨跌/PE/PB 粗筛，不是七维总分；要七维总分必须做「深度扫描」。
- 相似形态库只覆盖**已入库**股票的历史；库越小，结论越不稳。相似度是形态距离，不是因果，历史胜率也不保证未来。
- 原生 iOS 小组件需要 Xcode + 签名，本平台用 PWA 替代；手机访问依赖同一局域网和 Mac 开机。
- 前复权数据会随时间变化（每次除权后历史价格重算），所以不同日期跑出的历史分数会有细微差异。
- Web 平台默认只监听 `127.0.0.1`，没有登录鉴权，请勿直接暴露到公网。
- 本工具不构成投资建议。
